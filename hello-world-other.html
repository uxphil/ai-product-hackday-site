Other routes

These suit people who already use the tool. They’re not the quickest way to be ready, and we haven’t tested them yet.

Claude Code or Codex

These are terminal-style tools and need an install. You don’t need them for the warm-up. If you already have one working, ask it to create the index.html page from step 1, then follow the GitHub route from step 4 to upload and publish it. Official setup guides are on the resources page. If a command or permission request confuses you, don’t approve it: ask a helper.

Replit

Replit’s documentation (checked 7 October 2026) says the free Starter plan includes one free published app, which expires after 30 days. A warm-up app would use that slot, so you’d need to unpublish it before the day. For this reason we don’t recommend Replit for the warm-up unless you already use it. Connecting a Replit project to GitHub isn’t verified here: ask at the clinic.

Figma Make and others

If you plan to use another builder, check on your own personal account that you can build, publish and keep access to a project. Bring any questions to the clinic. Don’t use work accounts or work material for the warm-up.
