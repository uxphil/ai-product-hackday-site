Other tools

For people who already use a different builder. These aren’t the quickest way to be ready, and we haven’t tested them yet. If you use Claude or Codex, use their routes on the main page.

Please read this firstThis is a personal learning exercise. Use fictional or public sample content only. Do not enter, upload or share any LBG data in AI tools, GitHub repositories, prompts, screenshots or published websites. More on staying safe.

Lovable

Build in your browser and publish with one button. Free plan with a limited number of credits each day. Read the Lovable route.

Replit

Replit’s documentation (checked 7 October 2026) says the free Starter plan includes one free published app, which expires after 30 days. A warm-up app would use that slot, so you’d need to unpublish it before the day. We don’t recommend it for the warm-up unless you already use it. Connecting to GitHub isn’t verified here: ask at the clinic.

Figma Make and others

Check on your own personal account that you can build, publish and keep access to a project. Bring any questions to the clinic. Don’t use work accounts or work material for the warm-up.
