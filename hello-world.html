Hello-world warm-up

Ask an AI tool for a very simple web page and see it on your own computer. About 20–30 minutes. It’s a rehearsal for the day, not your hackathon product.

  1. Install a tool

    Claude or Codex, and sign in.

  2. Create a GitHub account

    Free and personal. We use it on the day.

  3. Ask for a page

    Answer the tool’s questions.

  4. See it

    On your own computer. Publishing is for the day.

Please read this firstThis is a personal learning exercise. Use fictional or public sample content only. Do not enter, upload or share any LBG data in AI tools, GitHub repositories, prompts, screenshots or published websites. More on staying safe.

Choose your tool

Both do the same job, and you’ll only see the instructions for the one you choose. Use whichever you already have, or are happiest to try.

You’ll work in a new, empty folder, and the page stays on your computer. On the day, your first exercise is to put it on GitHub and publish it, so you’ll also create a free GitHub account now.

Want to go further?

Once you’ve seen your page, you can add a smiley and even publish it a day early. That’s optional. Using another tool such as Lovable or Replit? See the other tools note.

  • Stays on your computer. Today’s page isn’t published, so nobody else can open it.

  • Your accounts. Use your own personal accounts, not a work account or work email.

  • Safety. Never paste a password, key or token into a chat. You shouldn’t need one for this exercise.

  • Costs. GitHub is free. If any screen asks for a card or offers a trial you didn’t plan for, stop and ask.
