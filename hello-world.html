Hello-world warm-up

One small page with a heading, a sentence and a button. Publish it, change it, publish again. It’s a rehearsal, not your hackathon product.

  1. Make a page

    About 10 minutes. No accounts needed.

  2. Save to GitHub

    Free personal account, public repository.

  3. Publish it

    An address anyone can open.

  4. Change and republish

    Prove you can iterate.

Please read this firstThis is a personal learning exercise. Use fictional or public sample content only. Do not enter, upload or share any LBG data in AI tools, GitHub repositories, prompts, screenshots or published websites. More on staying safe.

Choose how you’ll do it

All three end in the same place. The difference is how much you do by hand. You’ll only see instructions for the route you choose.

The agent routes aren’t much faster on the clock, because there’s an app to install. What they remove is the fiddly manual work, which is where most people get stuck. If you already pay for Claude, or use ChatGPT, they’re the better choice.

  • Public by design. The page you publish can be opened by anyone with the address. Use sample text only.

  • Your accounts. Use your own personal accounts, not a work account or work email.

  • Safety. Never paste a password, key or token. The agent routes sign in to GitHub with a one-time code in your browser.

  • Costs. The manual route is £0. If any screen on any route asks for a card or offers a trial you didn’t plan for, stop and ask. Other tools are covered separately.
