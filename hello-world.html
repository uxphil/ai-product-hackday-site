Hello-world warm-up

Ask an AI tool for a very simple web page and see it on your own computer. About 20–30 minutes. It’s a rehearsal for the day, not your hackathon product. The warm-up is optional, but please do it if you possibly can: it will make getting started much easier. Without it, you’ll spend some of the event setting up.

  1. Install a tool

    Claude or Codex, and sign in.

  2. Create a GitHub account

    Free and personal. We use it on the day.

  3. Ask for a page

    It may ask a question or two, or just make it.

  4. See it

    On your own computer. Publishing is for the day.

Please read this firstThis is a personal learning exercise. Use fictional or public sample content only. Do not enter, upload or share any LBG data in AI tools, GitHub repositories, prompts, screenshots or published websites. More on staying safe.

Choose your tool

Both do the same job, and you’ll only see the instructions for the one you choose. We recommend Claude, which needs a paid plan; buying one is your choice. No paid Claude plan? Use Codex: it works on a free ChatGPT account, within usage limits.

No personal laptop? Take part on your LBG laptop with Figma Make or on a phone or tablet.

You’ll work in a new, empty folder, and the page stays on your computer. On the day, your first exercise is to put it on GitHub and publish it, so you’ll also create a free GitHub account now.

Once you’ve seen your page, you’re ready. Stopping there is fine.

Optional extras

You can add a smiley and even publish it a day early. Using another tool such as Lovable or Replit? See the other tools note.

Next: look at the project themes

  • Stays on your computer. Today’s page isn’t published, so nobody else can open it.

  • Your accounts. Use your own personal accounts, not a work account or work email.

  • Safety. Never paste a password, key or token into a chat. You shouldn’t need one for this exercise.

  • Costs. GitHub is free, and buying an AI plan is up to you. If a screen unexpectedly asks for a card, an upgrade or a trial you didn’t plan for, stop and ask.
