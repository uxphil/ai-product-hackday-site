Hello-world warm-up · Lovable route

Build it in the browser with Lovable

Optional. Only if you plan to use Lovable on the day, and not needed to be ready. You can try it early or wait for the day.

Please read this firstThis is a personal learning exercise. Use fictional or public sample content only. Do not enter, upload or share any LBG data in AI tools, GitHub repositories, prompts, screenshots or published websites. More on staying safe.

Before you start: check the limits.

  • Lovable’s documentation (checked 7 October 2026) lists a Free plan with 5 build credits a day, up to 30 a month. Your prompt and each change use some, and building pauses when they run out.
  • Publishing is free and works even with zero credits. On Free and Pro plans, anyone with the link can open a published app.
  • The docs don’t say whether a card is needed to sign up. If you’re asked for one, stop and use the GitHub route.
  • We found no limit on the number of published projects, but that’s unconfirmed. We’ll verify it on a real account before the clinic.

These steps follow Lovable’s official documentation and haven’t yet been tried by us. Button names may differ slightly.

  1. Create a GitHub account first5–10 min

    You’ll save to GitHub at the end, so create or sign in to your personal account at github.com/signup. Your username is public.

  2. Sign up for Lovable3 min

    Go to lovable.dev and create a free account with your personal email.

  3. Ask for the page3 min

    Paste this into the chat.

    Create a single-page website with a heading that says "Hello, world", one friendly sentence, and a button that changes the sentence when clicked. Use sample text only. No sign-in, database or other services.

    Click the button in the preview to check it works.

  4. Publish2 min

    Click Publish at the top right, accept the suggested address (it ends in lovable.app) and click Publish again. Open the address on your phone.

  5. Change it and publish again3 min

    Ask in the chat: “Change the sentence to something else.” Then click Publish and Publish changes. Changes don’t go live until you do this. Reload your address to check.

  6. Save it to GitHub3–5 min

    Open Project settings → Git → GitHub, connect your GitHub account and let Lovable create the repository. The repository is private by default. Don’t delete it afterwards, or the link stops working.

You’re ready

  • You built a page in Lovable.
  • It’s published at an address someone else can open.
  • You changed it and published again.
  • It’s saved in your GitHub account.

On the day you’ll start a new Lovable project. Ask at the clinic if you’re unsure how your credits will cover a full day.
