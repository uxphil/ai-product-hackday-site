Hello-world warm-up · Claude

Ask Claude for a web page

You ask for a very simple page. Claude will ask you some questions, and you answer them. At the end you see your page on your own computer. About 20–30 minutes the first time (an estimate).

Please read this firstThis is a personal learning exercise. Use fictional or public sample content only. Do not enter, upload or share any LBG data in AI tools, GitHub repositories, prompts, screenshots or published websites. More on staying safe.

Needs a paid Claude plan (Pro or higher). Claude Code isn’t on the free plan. You do three things yourself: create the accounts, install the app and sign in, and check the result. Prefer to start with a free tool? Try Codex in the ChatGPT app.

Nothing is published today: the page stays on your computer. On the day we’ll put it on GitHub and publish it together, which is why you create a GitHub account now.

  1. Install the Claude app and sign in5–10 min

    Download the Claude desktop app for Mac or Windows, install it and sign in. Claude Code needs a paid Claude plan (Pro or higher): the free plan does not include it.

    Then click the Code tab at the top. If it asks you to upgrade or sign in on the web, do that first and restart the app.

  2. Create your GitHub account5–10 min

    We’ll use GitHub on the day to put your page online, so please have an account ready. Go to github.com/signup. GitHub Free needs no card. Use your own personal email and verify it. Your username is public and becomes part of your web address. Skip optional questions and paid-plan offers. Already have an account? Move on. You don’t need to do anything else with it today.

  3. Give it an empty folder to work in2 min

    1. Create a new, empty folder on your Desktop called hello-hackday (right-click the Desktop, then New Folder on Mac or New → Folder on Windows).
    2. In the Code tab choose Local, click Select folder and pick that folder.

  4. Ask for your page5–10 min

    Paste this into the chat and press Enter.

    I’d like you to create a webpage that simply says hello world.

    This prompt is short on purpose. Claude will probably ask you questions, for example what the page should look like or what to call it. Answer in your own words. If you don’t mind, say “you decide”. Talking it through like this is exactly what you’ll do on the day, so it’s part of the exercise.

    Claude will ask your permission before it does things. Read each request. It’s fine to approve creating files in your hello-hackday folder and opening the page. If it asks for anything else, say no and ask a helper.

    Something went wrong, or it asks for something odd
    • It asks for a password, key or token: stop. Say no. You don’t need one for this exercise.
    • It asks to do something unrelated to your hello-hackday folder: say no and ask a helper.
    • It suggests publishing, GitHub or extra features: say “not today, just the page on my computer”.
    • It stops or says you’ve run out of usage: wait and try again later, and tell Phil if it stays stuck. Don’t buy anything on the spot.

  5. See your page1–2 min

    Ask Claude: “Please open the page in my browser.” Or open the hello-hackday folder yourself and double-click the file ending in .html (probably index.html). You should see “hello world” in your web browser.

    The address at the top will start with file://. That means it’s only on your computer, so nobody else can open it yet. That’s fine.

You’re ready

  • Claude is installed and you’re signed in.
  • You have a GitHub account to use on the day.
  • You asked for a page, answered its questions and saw the result.

Keep the folder and bring your laptop. On the day, your first exercise is to put this page on GitHub and publish it.
