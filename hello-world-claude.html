Hello-world warm-up · Claude

Ask Claude for a web page

You ask for a very simple page. Claude may ask you a question or two first, or simply make it: either is fine. At the end you see your page on your own computer, and Claude is connected to your GitHub account, ready for the day. About 25–35 minutes the first time (an estimate).

Please read this firstThis is a personal learning exercise. Use fictional or public sample content only. Do not enter, upload or share any LBG data in AI tools, GitHub repositories, prompts, screenshots or published websites. More on staying safe.

Needs a paid Claude plan (Pro or higher). Claude Code isn’t on the free plan, and buying a plan is your choice, not a requirement. You do three things yourself: create the accounts, install the app and sign in, and check the result. Prefer to start with a free tool? Try Codex in the ChatGPT app.

Nothing is published today: the page stays on your computer. On the day we’ll put it on GitHub and publish it together, which is why you create a GitHub account now and connect Claude to it.

  1. Install the Claude app and sign in5–10 min

    Download the Claude desktop app for Mac or Windows, install it and sign in. Claude Code needs a paid Claude plan (Pro or higher): the free plan does not include it.

    Then click the Code tab at the top. If it asks you to sign in on the web, do that and restart the app. If it asks you to upgrade, your plan doesn’t include Claude Code: only buy one if you’d already decided to. Otherwise, use Codex for free instead.

  2. Create your GitHub account5–10 min

    We’ll use GitHub on the day to put your page online, so please have an account ready. Go to github.com/signup. GitHub Free needs no card. Use your own personal email and verify it. Your username is public and becomes part of your web address. Skip optional questions and paid-plan offers. Already have an account? Move on.

    Remember how you signed up: with an email and password, with Google, or with Apple, and on which device. Always sign in to GitHub the same way. A Google sign-in won’t find an account you made with Apple.

  3. Give it an empty folder to work in2 min

    1. Create a new, empty folder on your Desktop called hello-hackday (right-click the Desktop, then New Folder on Mac or New → Folder on Windows).
    2. In the Code tab, use the controls under the prompt box: choose Local, then Open folder…, and pick that folder. (Some versions say Select folder.)

  4. Ask for your page5–10 min

    Paste this into the chat and press Enter.

    I’d like you to create a webpage that simply says hello world.

    This prompt is short on purpose. Claude may ask you a question or two, for example what the page should look like, or it may just make the page straight away. Both are fine. If it asks, answer in your own words, or say “you decide”. Talking it through like this is what you’ll do on the day.

    Claude will ask your permission before it does things. Read each request. It’s fine to approve creating files in your hello-hackday folder and opening the page. If it asks for anything else, say no and ask a helper.

    Something went wrong, or it asks for something odd
    • It asks for a password, key or token: stop. Say no. You don’t need one for this exercise.
    • It asks to do something unrelated to your hello-hackday folder: say no and ask a helper.
    • It suggests publishing or extra features: say “not today, just the page on my computer”.
    • It stops or says you’ve run out of usage: wait and try again later, and tell Phil if it stays stuck. Don’t buy anything on the spot.

  5. See your page1–2 min

    Ask Claude: “Please open the page in my browser.” Or open the hello-hackday folder yourself and double-click the file ending in .html (probably index.html). You should see “hello world” in your web browser.

    The address at the top will start with file://. That means it’s only on your computer, so nobody else can open it yet. That’s fine.

  6. Connect Claude to GitHub5–10 min

    This lets Claude put your page on GitHub on the day, with one request. You won’t type a password, and Claude won’t open a browser. GitHub gives you a short one-time code, and you type it in yourself.

    First, be signed in to GitHub somewhere: in your usual browser, or on your phone if that’s where you signed up. In the same chat, paste this.

    Please connect this computer to my GitHub account, ready for the day. Go one step at a time and explain each step in plain language. 1. Check that Git and the GitHub CLI (gh) are installed. If either is missing, tell me what you need to install and ask before you do it. 2. Run gh auth login --hostname github.com --git-protocol https --web in the background, then show me the one-time code clearly. Don’t open a browser or use any browser tools: I’ll type the code myself at github.com/login/device. Never ask me for a password or token. 3. When I say done, run gh auth setup-git and gh auth status, and tell me my GitHub username. Don’t create a repository or publish anything today.

    When Claude shows the code (it looks like ABCD-1234), go to this address on any device where you’re signed in to GitHub, your phone included:

    github.com/login/device

    Type the code, press Continue, then Authorize. Tell Claude “done”. The code works for about 15 minutes, so do it in one go.

    It’s fine to approve Claude using git and gh, and installing them if it asks. You’re finished when Claude tells you your GitHub username.

    Something went wrong, or it asks for something odd
    • It asks for a password or token: say no. Say “Don’t ask for a password or token. Use the one-time code instead.”
    • A browser tab opens anyway: close it, and type the code at github.com/login/device in a browser where you’re already signed in, or on your phone.
    • GitHub asks you to sign in and you can’t: use the same method you signed up with (email, Google or Apple), or switch to the device you signed up on. Made it with Apple on your phone? Type the code on your phone.
    • A Mac pop-up asks to install developer tools: choose Install and wait. It can take a few minutes.
    • On Windows it can’t install Git or the GitHub CLI: ask it to explain the manual download, or bring it to a setup clinic.
    • The code ran out: say “Please start the GitHub sign-in again”.

You’re ready

  • Claude is installed and you’re signed in.
  • Claude is connected to your GitHub account.
  • You asked for a page and saw the result.

Keep the folder and bring your laptop. On the day, your first exercise is to put this page on GitHub and publish it. Because you’re connected, that’s one request.
